# 界面重设计 · Claude Design 任务书（v2.0 增量）

> 用途：投喂给 Claude Design 项目「小说阅读软件设计」，在既有 55 画板（P0/P1/P2 三面画板墙）基础上按 v2.0 需求做增改。
> 权威来源：《界面重设计需求文档 v2.0》（`docs/界面重设计需求文档.md`），本文只列增量、修改点与工作顺序；行为细节与页面清单一律以 v2.0 为准。
> 性质：不是推倒重画。视觉语言、令牌、组件 kit 全部沿用；改的是信息架构、若干页面的结构，以及一批新增画板。

## 1. 不变的硬约束（画板墙已确立，继续沿用）

1. 种子色石墨青 `#35606E`，日光/夜墨双主题；组件只引用语义色槽位（primary / surface / surfaceContainer 1–4 / outline / error），不硬编码色值。
2. 正文纸色是独立调色板（纸/白/绿/夜 + 纯黑 + 墨水屏两个变体 + 背景图分支），不随 App 主题联动；阅读面衬线体、操作面无衬线体。
3. 字阶、形状（16/20/12/28 高频圆角）、2dp 间距网格照旧；手机画板 390×844；自适应见 X-01/X-02。
4. 触点 ≥48dp；UI 正文 ≥14sp；阅读正文默认 17sp，放大到 26sp 不溢出。
5. 原五条设计契约继续有效（语义色、阅读面/操作面分离、状态优先于成功态、触点字号下限、设置路由重排）。

## 2. 本轮新决策（所有画板需要体现）

### 2.1 一级导航职责重定义

| Tab | 新职责 | 与旧稿的差别 |
| --- | --- | --- |
| 首页（可隐藏） | 个人聚合：继续阅读、目标与统计摘要、备份**状态提醒**、精选发现模块 | 备份卡片不再是操作面，只做状态 + 深链；模块流点击一律进发现分类页，首页不持有平行浏览系统 |
| 书架 | 我的书 | 搜索按钮**只做书架内过滤**；空结果给"全网搜索『关键词』"显性跳转 |
| 发现 | **找书中枢**：顶部常驻全局搜索框 + 书源发现分类 | 搜索与发现合体；这是全局搜索在手机上的唯一常驻入口 |
| 订阅（RSS，可隐藏） | RSS 闭环 | 不变，默认可隐藏 |
| 我的 | 每天要动的：主题快捷切换（日光/夜墨 + 进完整主题页）、书签、阅读记录与统计、AI 对话；加"源与规则"聚合入口、Web 服务状态行、设置、关于 | 旧稿"我的"里的 5 个规则页收进"源与规则"一个入口；缓存/文件管理下沉设置；退出移入关于 |

### 2.2 结构性决定

- 设置中心 = C-01 三组七入口（已画且已实现，视为定稿）；**"其他设置"页取消**；主题不在设置里，挂在"我的"（N-04）。
- 阅读器菜单从"平铺路由 + 大量 Sheet"改为**真实层级**（见 §3 的 R 系列修改点）；"更多设置"面板取消，改为深链到设置→阅读与排版。
- 外观类参数堆（阅读菜单外观、页眉页脚、漫画面板、书架显示）一律**预设制**：2–4 个预设卡 + 一个集中"自定义"入口（P2），不再平铺滑杆。
- 五种交互模板全 App 共用（§4），任何页面不得自绘同类变体。
- 弹层分层：Dialog 只做确认/单值输入；BottomSheet 做上下文选择与轻设置（嵌套 ≤2 层、不建私有导航栈）；长列表与多步流程用整页。

## 4. 需新增的画板

### 4.1 交互模板规范稿（5 张，新增交付物，优先级最高）

所有相关页面标注引用模板，不再各自为政：

1. **高级列表**（源与规则通用）：基线能力（搜索/多选/启停/拖拽/导入导出/编辑/删除确认）+ 可选插槽（分组、置顶置底、排序、可用性检查、调试、内置导入、扫码导入、冲突策略）。
2. **导入审核**：应用内、外部链接、文件关联三条路径汇入同一面板；全选、按状态筛选（新增/更新/冲突）、逐项编辑、冲突策略；来源选择并入首步。
3. **选择态**：底部浮动条 `[全选][反选][已选 N] … [主操作][更多▾]`；主操作按对象类型；删除一律进"更多"+二次确认。
4. **搜索**：仅两种形态——列表内联过滤（顶栏搜索态）与全局搜索页；正文搜索为阅读器内覆盖层。
5. **弹层与长任务反馈**：Dialog/Sheet/整页分层规则；长任务的"进行中"统一语言（持续进度 + 逐项状态 + 取消 + 完成摘要）；Toast 不承载唯一重要信息。

## 5. 状态稿底线

每个网络/数据页面：骨架屏、空状态（原因 + 下一步）、局部失败/整页失败、离线、进行中（可取消）、成功/失败提示、危险操作确认。文字阅读器至少交付：纯阅读、菜单、搜索、夜间纸色、加载失败、TTS 运行、选中文本、翻页动画、大字号九张稿。

## 6. 建议工作顺序

1. **五张模板规范稿**（§4.1）——后续所有页面引用它们，先定。
2. **阅读器 R 系列重构**（§3 中 R-01a/R-02/R-03/R-05/R-14）——决策最密集，牵动纸色、排版、菜单体系。
3. P0 其余修改：M-01、B-01 系、S-01/S-04/S-06/S-07、P-01。
4. P1 新增与修改：D-00、S-08、设置子页、V-02、F-02、G-01。
5. P2：M-02a、深度自定义（菜单外观编辑器）、Q 系列低频页。

完成后更新画板索引，并按 v2.0 §17 要求同步维护「旧功能—新去向映射表」。
